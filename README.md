# AGENT-OS —— AI 操作系统

> **Personal AI Operating System in plain text.**
> 一套纯文本文件：全局宪法 + 项目 AGENTS.md + 观澜板 + skill 指针库。
> 任何 AI 工具——Claude Code、Codex、Cursor、纯 VSCode、裸 API 调 某大模型——
> 读了这套文件就能按你的规矩上岗。**工具随时换，真理不动。**

## 解决什么问题

大模型本身无记忆、无家——它的"记忆"永远是每次对话开头塞进去的那段话。
所以别把规矩写进任何工具的私有配置里，**把规矩写成文件**，让所有工具来读：

- 换工具（Claude Code → Codex → 裸 API）：只换"影子"，宪法不动
- 换电脑：clone 本仓库，从模板生成自己的实例，10 分钟冷启动
- 换项目：进哪个项目读哪家的 AGENTS.md，纪律自动分层，互不污染
- 多项目总览：观澜板每项目 3 行，AI 干完活自更新，一眼知全部

## 术语速览（陌生 AI 先在这里补课）

- **skill**：任意来源的可复用提示词/装备——社区 skill、公司规范文档、个人装备库都算。
  项目用到哪些，就在该项目 AGENTS.md 清单里登记哪些（指针式，全局改了全项目实时生效）。
- **观澜板**：INDEX.md，每项目 3 行的粗粒度状态视图，只在大节点更新，日常一致性由
  看板夜间巡检（git log 哨兵）兜底。
- **影子**：各工具的全局注入文件（~/.claude/CLAUDE.md、~/.codex/AGENTS.md 等），
  都是 GLOBAL-MASTER.md 的副本；母版改了影子同步，换工具只换影子。
- **审计三件套**：公开仓上架前检查 = 资金语义扫描 + 凭据形式扫描 + 截图目检。

## 三种接入模式（不默认任何工具，全部兼容）

**给 AI 的说明：你不需要判断自己处于哪个模式。** 模式只影响"影子安装"这一步（由人执行）；
接入完成后，任何模式下 AI 的行为完全一致——读文件、守规矩、干活。

**模式 A：带自动注入的 agent 工具**（Claude Code / Codex / Cursor agent 模式）
→ 按 INSTALL.md 把 GLOBAL-MASTER.md 影子化到该工具的全局路径。
之后每次进任何项目目录，规矩自动生效，你无感。

**模式 B：纯 VSCode + AI 聊天插件**（Copilot / Cline / 任意，没有全局注入机制）
→ 每个新会话第一句发**注入头**（正式文案在 INSTALL.md 模式 B，复制即用），
指向本仓库 README，由它带路。核心一句：
> 我的全局规矩和项目地图在 ~/Developer/agent-os/，先读 README.md，按它的指引干活。

**模式 C：裸 API**（某大模型 / 某 LLM 服务商 / 任意 OpenAI 兼容接口）
→ system prompt 拼接规则见 INSTALL.md 模式 C：GLOBAL-MASTER 全文 + 当前项目
AGENTS.md + 一句"冲突先指出再询问"。母版是唯一真理，别手抄进 prompt。

## 设计原则（为什么这样能兼容一切）

1. **真理住在文件系统**——规矩写成纯文本文件，不写成任何工具的私有配置。
2. **工具注入文件 = 影子**——母版唯一真理，影子可丢可重建。
3. **无注入器也能跑**——模式 B/C 证明：最差情况下"一句话+一个文件路径"就是完整接入。
4. **本机痕迹零泄漏**——实例、凭据、运行时数据、个人产出全部 gitignore，
   仓库里只有模板与规矩；公司私有库场景下，实例靠本地快照（tools/instance-snap.sh）做版本控制。

## 快速开始（新电脑）

1. clone 本仓库到 ~/Developer/agent-os
2. 读《使用手册.md》场景"新电脑冷启动五步"
3. cp 两个模板生成实例 → 填你的身份 → INSTALL.md 逐项打勾
