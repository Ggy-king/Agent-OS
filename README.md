# AGENT-OS —— 这台电脑的 AI 总控（母版目录）

> **一句话**：真理只存在于这个文件夹里的纯文本文件。任何工具——Claude Code、Codex、Cursor、
> 纯 VSCode、裸 API 调 某大模型——都只是"把这里的文件喂给大模型"的不同方式。
> 工具可以随时换，这个文件夹不动。

## 术语速览（陌生 AI 先在这里补课）

- **skill**：任意来源的可复用提示词/装备——社区 skill、公司规范文档、EXO 装备（E02/E09/E19-E23
  等编号装备，存于 ~/Developer/exo/prompts/）都算。项目用到哪些，就在该项目 AGENTS.md 清单里登记哪些。
- **worker**：某个项目目录里被该项目 AGENTS.md 装备起来的 AI 会话角色。
- **审计三件套**：公开仓上架前检查 = 资金语义扫描 + 凭据形式扫描 + 截图目检（细则在 chanGy 项目档案）。
- **大脑切换**：xiaoke-app 项目内部术语（指更换其 AI 大脑），详见该项目 AGENTS.md（待建）。

## 三种接入模式（不默认任何工具，全部兼容）

**给 AI 的说明：你不需要判断自己处于哪个模式。** 模式只影响"影子安装"这一步（由人执行）；
接入完成后，任何模式下 AI 的行为完全一致——读文件、守规矩、干活。

**模式 A：带自动注入的 agent 工具**（Claude Code / Codex / Cursor agent 模式）
→ 按 INSTALL.md 把 GLOBAL-MASTER.md 影子化到该工具的全局路径。
之后每次进任何项目目录，规矩自动生效，你无感。

**模式 B：纯 VSCode + AI 聊天插件**（Copilot / Cline / 任意，没有全局注入机制）
→ 每个新会话第一句话发这段"注入头"（**全体系唯一入口句**，与 INSTALL 模式 B 逐字一致，复制即用）：
> 我的全局规矩和项目地图在 ~/Developer/agent-os/，先读 README.md，按它的指引干活。

**模式 C：裸 API**（某大模型 / 某 LLM 服务商 / 任意 OpenAI 兼容接口）
→ 把 GLOBAL-MASTER.md 全文放进 system prompt（全文几百字，token 成本可忽略），
项目细节按需把对应项目 AGENTS.md 内容附进上下文。

## 设计原则（为什么这样能兼容一切）

1. **真理住在文件系统**——大模型本身无记忆无家，它的"记忆"永远是每次对话开头塞进去的话。
   所以规矩写成文件，不写成任何工具的私有配置。
2. **工具注入文件 = 影子**——~/.claude/CLAUDE.md、~/.codex/AGENTS.md 等都是 GLOBAL-MASTER.md
   的副本，母版改了影子跟着同步；换工具只换影子，真理不动。
3. **无注入器也能跑**——模式 B/C 证明了这一点：最差情况下"一句话+一个文件路径"就是完整接入。
